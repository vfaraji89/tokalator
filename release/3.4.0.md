# Website release 3.4.0

The homepage introduces locally generated GLOSSARY.md and SITE-MAP.md as the release's main feature. A downloadable automation kit contains the Python generator, installer, review commands, tests and MIT license. The site remains AGPL-3.0-or-later.

The kit installs Claude Code SessionStart, review-prompt and Stop hooks. Other coding agents use the generated Markdown and CLI directly. Source links and hashes support navigation; the documents do not prove behavior. Python extraction uses AST; JS/TS extraction is heuristic.

The release also updates selected provider pricing with dated official references, implements applicable long-context costs, labels dashboard simulation clearly, and fixes duplicate catalog IDs and deployment tracing. Dependency updates resolve the vulnerabilities reported by npm audit at preparation time.
