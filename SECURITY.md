# Security policy

## Supported versions

Security fixes go to the latest release of the VS Code extension and the Claude Code plugin.

## Reporting a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/vfaraji89/tokalator/security/advisories/new).

Include the component, version, reproduction steps and impact. You will get a first response within 5 business days, and accepted reports are disclosed after a fix ships.
